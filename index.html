ABOUT ZKAS

A private-by-default proof-of-work BlockDAG.

ZKAS combines a Kaspa-derived GHOSTDAG consensus engine with Orchard shielded transactions and Halo 2 zero-knowledge proofs. The result is a network designed for private transfers at a one-second block target, secured by kHeavyHash proof of work and merge-mineable alongside Kaspa.

ConsensusGHOSTDAG BlockDAG
PrivacyOrchard + Halo 2
MiningkHeavyHash
Block target~1 second
LaunchNo premine
01

Shielded from the start

Every normal transfer is shielded. Amounts, sender and recipient are hidden by construction rather than through an optional privacy mode.

02

Parallel proof of work

Blocks form a DAG instead of a single chain. GHOSTDAG orders parallel blocks into one accepted history while maintaining proof-of-work security.

03

Open and verifiable

The protocol, node software and monetary rules are public. ZKAS launched without a presale, founder allocation or spendable genesis premine.

DISCOVER

Privacy at settlement speed.

ZKAS is a from-genesis cryptocurrency designed around mandatory shielded transfers, proof-of-work security, and a parallel BlockDAG architecture.

01

Mandatory privacy

Payments use Orchard shielded transactions with Halo 2 proofs. There is no transparent transfer mode.

02

One-second target

GHOSTDAG orders blocks produced in parallel, with a target of roughly one block per second.

03

Kaspa merged mining

ZKAS uses kHeavyHash and can be merge-mined alongside Kaspa, allowing the same work to secure both networks.

PRIVACY

Amounts, senders and recipients are hidden by construction.

ZKAS uses Zcash-derived Orchard privacy and Halo 2 zero-knowledge proofs on top of a Kaspa-derived GHOSTDAG engine. The network is designed so private transfers are the standard behavior, not an optional mode.

The protocol is open source. The project states that its novel shielded-state integration has not yet had an independent external audit, so users should verify current software and documentation before moving funds.
