# ZKAS.io

Community website for ZKAS.io.

This repository contains the current source for https://zkas.io, including the animated BlockDAG homepage, About, Get Started, Tokenomics, Wallets & Exchanges, Mining, Build, Network, and the Cloudflare-backed site-view counter frontend.

## Deployment

The site is intended to deploy from the `main` branch through Cloudflare. Static site files live at the repository root.

## Site view counter

See `README-CLOUDFLARE-SITE-VIEWS.md` and `cloudflare-view-counter-worker.js` for the separate Cloudflare KV counter Worker setup.
